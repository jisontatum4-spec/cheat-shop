# ShadowForge Cheats — Static Shop

Ready for GitHub Pages.

## How to host free on GitHub

1. Create a new repository (example: `cheat-shop`)
2. Upload all files in this folder (`index.html`, `style.css`, `script.js`, `README.md`)
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main` / root
5. Save. Your site will be live at:
   `https://YOURUSERNAME.github.io/cheat-shop/`

## Customize before going live

- Replace every `https://t.me/yourchannel` with your real Telegram link
- Edit product names, prices, descriptions in `index.html`
- Change logo text / colors in `style.css` if you want

## Notes

- Pure static (HTML + CSS + JS)
- No backend, no database
- Mobile responsive
- Dark cyber theme
